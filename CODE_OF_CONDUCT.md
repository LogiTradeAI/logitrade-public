# Code of Conduct

## Our Commitment

LogiTrade is committed to creating an open, respectful, and professional environment for everyone participating in the project.

We value collaboration, innovation, and constructive communication. All contributors, users, and community members are expected to interact with respect and help maintain a positive environment.

---

# Expected Behavior

Community members should:

* Communicate respectfully and professionally.
* Provide constructive feedback.
* Respect different opinions and approaches.
* Focus discussions on improving the project.
* Share knowledge and help others learn.
* Follow responsible development practices.

---

# Unacceptable Behavior

The following behaviors are not acceptable:

* Harassment or discrimination.
* Personal attacks or insulting behavior.
* Threats or intimidation.
* Deliberate disruption of discussions or development.
* Sharing private or confidential information.
* Unauthorized disclosure of security issues.
* Malicious actions against the project or its users.

---

# Technical Discussions

Technical discussions should remain focused on improving LogiTrade.

Contributors should:

* Provide clear explanations.
* Support suggestions with reasoning or evidence.
* Accept constructive criticism.
* Avoid unnecessary arguments or personal disputes.

Disagreements are expected in technical projects. They should be handled professionally and respectfully.

---

# Security Responsibilities

Security issues require responsible handling.

Community members should:

* Avoid publicly sharing vulnerabilities before they are addressed.
* Report security concerns privately.
* Provide enough information to help investigate issues.

Please refer to:

```text
SECURITY.md
```

for security reporting guidelines.

---

# Contribution Standards

Contributors are expected to:

* Follow project guidelines.
* Maintain code quality.
* Respect intellectual property.
* Avoid introducing harmful changes.
* Consider user safety and platform reliability.

---

# Community Moderation

Maintainers may remove, edit, or reject contributions that violate this Code of Conduct or negatively impact the project community.

Repeated violations may result in restrictions from participating in project discussions or contributions.

---

# Reporting Issues

If you experience or witness unacceptable behavior, report it through the appropriate project communication channels.

Reports should include:

* Description of the issue.
* Relevant context.
* Any supporting information.

All reports will be reviewed as fairly and confidentially as possible.

---

# Scope

This Code of Conduct applies to:

* Repository contributors.
* Community members.
* Issue discussions.
* Pull requests.
* Public communication channels related to LogiTrade.

---

# Final Statement

LogiTrade believes strong communities are built through respect, transparency, and collaboration.

By participating in this project, you agree to help create a professional environment where innovation and responsible development can continue.
