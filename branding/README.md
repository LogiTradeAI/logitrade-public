# Brand Usage

LogiTrade branding should be used accurately and respectfully.

Approved usage includes:

* Product discussions.
* Educational materials.
* Authorized partnerships.
* Community references.

---

# Restricted Usage

The LogiTrade brand should not be used to:

* Suggest unauthorized partnerships.
* Create misleading materials.
* Imply guaranteed trading results.
* Modify official branding without approval.
